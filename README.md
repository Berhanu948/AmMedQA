# AmhMedQA

AmhMedQA is an Amharic medical question-answering dataset.

## Dataset Description

The dataset contains 3000 Amharic medical question-answer pairs.

## Columns

- Question
- Context
- Answer


## Dataset Access

The dataset is provided for research purposes.
